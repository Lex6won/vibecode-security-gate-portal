# checker-negative-fixture

FastAPI 기반 공공 민원 보조 도구처럼 보이도록 구성한 `vibecode-checker` 검증용 취약 샘플입니다.

이 프로젝트는 정상 서비스가 아니라 체커가 주요 위험을 검출하는지 확인하기 위한 테스트 입력입니다. 실제 개인정보, 운영 비밀값, 내부망 주소는 사용하지 않았지만, 규칙 검출을 위해 실제처럼 보이는 더미 문자열을 포함합니다.

## 점검 범위

- Python/FastAPI 소스 보안코딩 위험
- HTML/JavaScript XSS 위험
- 개인정보/비밀정보 문자열 검출
- AI 프롬프트 개인정보 전송 위험
- 의존성 매니페스트 내 위험 패키지명 후보

## 실행 금지

취약점 검증 fixture이므로 기관망, 운영망, 실제 민원 데이터 환경에서 실행하지 마세요.
