# 포털 UI 참고 이미지
8~10씬에서 사용한 포털 화면을 기존 포털 UI와 기능을 보완할 때 참고할 수 있도록 순서대로 저장한 자료입니다.

## 적용 순서

| 순서 | 파일 | 화면 역할 | 반영할 핵심 기능 |
|---|---|---|---|
| 01 | `01-scene-08-home-security-check.png` | 포털 메인 | `보안 점검`을 가장 눈에 띄는 주 진입점으로 제공 |
| 02 | `02-scene-09-scan-report-flow.png` | 점검 진행 흐름 | 대상 선택 → 점검 기준 선택 → 점검 실행 → 결과 확인 → 보고서 저장 |
| 03 | `03-scene-10-result-review-request.png` | 점검 결과·검토 요청 | 점검 완료 요약, HTML·JSON 보고서 다운로드, `보안성검토 요청` 접수 |

## 구현 시 유지할 흐름

1. 사용자는 메인 화면에서 `보안 점검`을 클릭한다.
2. 점검 대상과 점검 기준을 선택하고 몇 번의 클릭으로 점검을 실행한다.
3. 취약점과 SBOM 등 결과를 확인하고 HTML·JSON 보고서를 저장한다.
4. 저장된 근거를 첨부해 `보안성검토 요청`을 접수한다.
5. 포털은 요청과 자료를 정리하며, 최종 승인·판단은 보안담당자가 수행한다.
