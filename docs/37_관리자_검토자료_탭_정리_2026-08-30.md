# 관리자 검토 자료 탭 정리

## 목적

관리자 화면은 보안성검토를 승인하거나 반려하는 대기열이 아닙니다. 제출된 검토 자료를 확인하고 출력하거나 저장하는 용도로만 제공합니다.

## 화면 변경

- `검토 요청·운영` 탭과 서버 상태 영역을 제거했습니다.
- 탭 이름을 `검토 자료`로 바꿨습니다.
- 제출한 보안성검토 자료만 목록에 표시합니다.
- 각 자료에서 요청서는 `보기`, `출력`할 수 있습니다.
- 제출자료 ZIP은 `저장`으로 내려받을 수 있습니다.
- 검색, 점검 결과 필터, 페이지당 표시 건수, 페이지 이동은 유지합니다.

## 데이터 규칙

- 검토 자료는 사용자가 보안성검토 제출을 완료한 점검에만 생성됩니다.
- 요청서와 제출자료 ZIP의 파일 종류를 API가 명시적으로 전달합니다.
- 임시 개발 이메일은 검토 자료의 요청자 칸에 노출하지 않고 `미확인`으로 표시합니다.
