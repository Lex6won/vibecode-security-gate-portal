# 집 노트북 테스트 서버 구축 — 클로드코드 작업 지시서

> **이 문서를 읽는 너(클로드코드)의 임무**: 이 Windows 노트북을 vibecode-security-gate-portal 의
> **상시 가동 테스트 서버**로 만드는 것. 아래 순서대로 진행하고, 각 단계의 검증을 통과해야 다음으로 간다.
> 사용자(원준석, 경기도 AI산업육성과)는 옆에서 관리자 권한 승인과 값 입력만 한다.

## 0. 배경 (1분 요약)

- 이 포털은 공무원이 AI로 만든 소스를 업로드하면 서버의 체커(gvskb)가 보안점검하고,
  패키지 관측을 축적해 경기도 화이트리스트 근거를 만드는 시스템이다.
- 역할 경계(필독: `docs/27_사업목표와_도구별_역할합의_2026-08-28.md`):
  체커=관측(보안 완벽), 하네스=집행, **포털=편의**, 판정=보안부서. 포털 코드에서 판정을 완화하는 로직을 만들지 마라.
- P1~P5 구현 완료. 업무 PC에서 "클론→npm ci→.env→기동→스모크"까지는 이미 실측 통과했다(2026-08-28).
  **이 노트북에서 남은 것은 §3~§6 — 서비스화(상시 가동)와 실기기 검증이다.**
- 상세 절차의 정본은 `docs/29_서버_구축_절차서.md` — 이 지시서와 다르면 29번이 우선.

## 1. 사전 준비 확인

```powershell
node --version    # 없으면 Node LTS 설치 (nodejs.org)
git --version
python --version  # Microsoft Store 파이썬이면 안 됨(가짜 스텁) — Miniconda 설치 권장
```

- 설치 위치는 반드시 **OneDrive 등 동기화 폴더 밖**: `C:\servers\` 를 만든다.
- 이 셸은 PowerShell 5.1일 가능성이 높다: `&&` 없음 — 명령을 줄로 나눠 실행하라.

## 2. 소스·체커 설치

```powershell
mkdir C:\servers
cd C:\servers
git clone https://github.com/Lex6won/vibecode-security-gate-portal
git clone https://github.com/Lex6won/vibecode-checker
cd vibecode-security-gate-portal
npm ci
cd ..\vibecode-checker
pip install -e .
gvskb doctor
```

- 저장소가 비공개라 GitHub 인증이 필요할 수 있다 — 사용자에게 브라우저 인증(git credential manager)을 요청하라.
- `gvskb doctor` 는 ERROR 없이 끝나야 한다(WARN 은 기록만 하고 진행).

## 3. 서버 설정 (.env)

```powershell
cd C:\servers\vibecode-security-gate-portal
copy config\server.env.example .env
```

`.env` 를 열어 다음을 채운다 (각 항목 설명은 example 파일 주석에 있음):

| 키 | 값 |
|---|---|
| `PORT` | 8787 |
| `PORTAL_BIND_HOST` | `0.0.0.0` |
| `PORTAL_ALLOWED_HOSTS` | `<노트북IP>:8787` — IP는 `ipconfig` 의 IPv4 주소. 공유기에서 이 노트북 IP를 고정(DHCP 예약)하도록 사용자에게 안내 |
| `ADMIN_ID` | 사용자에게 물어볼 것 (기관 이메일) |
| `ADMIN_INITIAL_PASSWORD` | 개발 환경과 동일하게 유지할 12자 이상 관리자 비밀번호 |
| `ADMIN_CREDENTIALS_SYNC` | `true` — 저장된 관리자 인증 해시를 위 비밀번호로 동기화 |
| 데이터 5경로 | `C:\portal-data\...` (scan-history·observations·accounts·whitelist·reports) |

**절대 규칙: 비밀값은 `.env` 에만. 어떤 파일로도 커밋하지 마라** (.env 는 gitignore 되어 있다).

## 4. 서비스화 (상시 가동)

1. https://nssm.cc 에서 nssm.exe 를 받아 `C:\servers\tools\nssm.exe` 에 둔다.
2. **관리자 권한 PowerShell** 에서:

```powershell
cd C:\servers\vibecode-security-gate-portal
.\scripts\setup-server.ps1 -Port 8787
```

- 이 스크립트가 사전 점검 → 방화벽(Private 프로파일, 해당 포트만) → NSSM 서비스 등록(자동 시작·크래시 재시작·로그 회전) → 전원 설정(절전 끔·덮개 닫아도 실행)까지 한다.
- 확인: `Get-Service VibeCodePortal` → Running.

## 5. 스모크 테스트 (전부 통과해야 완료)

| # | 검증 | 방법 |
|---|---|---|
| 1 | health | `Invoke-RestMethod http://127.0.0.1:8787/health` → ok |
| 2 | 화면 | 브라우저 `http://127.0.0.1:8787` → 메인 표시 |
| 3 | 가입·로그인 | /scan 에서 이메일(@gg.go.kr)+기관·부서 입력 → 링크 받기 → 화면의 "로그인 완료하기" 클릭(개발 모드라 링크가 화면에 뜨는 게 정상) |
| 4 | 실제 점검 1건 | 예제 폴더 업로드 → 간편 점검 → 보고서가 선택한 PC 폴더에 저장되는지 |
| 5 | 다른 기기 | 같은 와이파이의 휴대폰 브라우저 → `http://<노트북IP>:8787` → 메인 표시. 안 되면: 방화벽 규칙·공유기 AP 격리(isolation) 설정 확인 |
| 6 | **재부팅 생존** | 노트북 재부팅 → 서비스 자동 시작 → 1·5 재확인 |
| 7 | 데이터 위치 | `C:\portal-data\` 아래에 이력·계정 파일이 생기고, 코드 폴더 안에는 안 생기는지 |

## 6. 하지 말 것

- **인터넷 직접 공개 금지**: 공유기 포트포워딩·DDNS 열지 마라. 외부(도청) 접속은 나중에
  Cloudflare Tunnel + Access(@gg.go.kr·@korea.kr 관문)로만 — 사용자가 명시적으로 시키면 `docs/29 부록 A-1` 대로.
- 판정·검사 로직 수정 금지. 이 작업은 배포·설정이다.
- 이후 코드 갱신은 `main` pull 이 아니라 **태그 배포**: `.\scripts\deploy-server.ps1 -Tag v0.x.x`.
- 커밋할 일이 생기면(절차서 오류 수정 등): pre-commit 이 전체 guard 를 돌려 **2~4분** 걸린다 — 타임아웃 넉넉히. 커밋 시 `docs/12` 연혁도 함께 갱신.

## 7. 함정 모음 (업무 PC에서 이미 겪은 것들)

- PowerShell 5.1: `&&`·삼항·`??` 없음. 명령은 줄로 나눠라.
- Microsoft Store 파이썬은 가짜 스텁(exit 49) — Miniconda 의 python 을 쓸 것.
- 한국어 파일명 git 작업 시 `git -c core.quotepath=false`.
- node 로 재귀 삭제가 필요하면 동기 `rmSync` 대신 비동기 `fs/promises.rm` (환경에 따라 rmSync 가 조용히 죽는 사례 있음).
- 테스트 서버가 죽어 포트를 물고 있으면: `Get-NetTCPConnection -State Listen` 으로 찾은 PID 를 `Stop-Process`.
