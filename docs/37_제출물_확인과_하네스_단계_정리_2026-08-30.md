# 제출물 확인과 하네스 단계 정리

## 변경 목적

- 제출 완료 후 사용자가 ZIP 저장 여부와 서버 보관 산출물을 혼동하지 않도록 한다.
- 하네스 상단 단계명이 실제 화면의 내려받기, 설치, 설정 흐름과 일치하도록 한다.

## 제출 완료 후 동작

1. `보안성검토 자료 제출`은 요청서와 점검 리포트를 포함한 제출자료 ZIP을 생성하고 저장한다.
2. 완료 화면의 `제출물 확인하기`는 `/my?scan=<점검 ID>`로 이동해 해당 점검 이력 행을 강조한다.
3. `마치기`는 홈으로 이동한다.
4. HTML, JSON, Markdown, SBOM은 서버 보관본을 새 창에서 본다. 제출자료 ZIP은 외부 제출용 압축 파일이므로 내려받는다.

## 브라우저 제약

웹 페이지는 Windows 탐색기에서 사용자의 다운로드 또는 선택 폴더를 임의로 열 수 없다. 이는 브라우저 보안 제약이다. 따라서 폴더 열기처럼 보이는 버튼을 제공하지 않고, 서버에 90일 보관된 제출물을 이력 화면에서 확인하도록 한다.

## 반응형 확인

- 모바일 이력은 가로로 긴 표 대신 점검 건별 카드로 표시한다. 각 값에는 일시, 대상, 결과, 산출물 등의 항목명이 함께 보인다.
- 하네스 단계 표시줄은 작은 화면에서 여백과 글자 크기를 줄여 마지막 단계까지 한 화면 안에 표시한다. 보안점검의 4단계는 모바일에서 2행 2열로 표시한다.
- 공통 헤더는 모바일에서 로고와 서비스명을 축소하고, 우측 작업 버튼을 다음 줄의 왼쪽부터 배치한다.
- 홈의 긴 제목과 설명은 모바일에서 줄바꿈을 허용해 가로 넘침을 막는다.
- 이력의 보안성검토 상태는 데스크톱에서도 열 너비 안에서 줄바꿈해 요청 상태와 시간을 모두 표시한다.
