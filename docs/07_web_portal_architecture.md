# 웹 포털 아키텍처 설계

## 핵심 판단

서비스의 주 화면은 웹 포털로 만든다.

다만 사용자의 PC에 설치된 하네스, 체커, MCP 설정, 로컬 소스 폴더를 확인하려면 브라우저만으로는 부족하다. 따라서 포털은 다음 두 계층으로 설계한다.

1. 중앙 웹 포털
2. 로컬 브릿지

## 계층별 역할

### 중앙 웹 포털

기관 공통 화면과 기록을 담당한다.

- 서비스 안내
- 검사 이력 조회
- 관리자 현황
- 제출 가능 상태 통계
- 체커 개선 항목 관리
- 기관 정책과 업데이트 채널 표시
- 보고서 메타데이터 관리

중앙 웹 포털은 사용자의 원본 소스코드를 기본 저장하지 않는다.

### 로컬 브릿지

사용자 PC에서 실행되는 작은 로컬 프로세스다.

- 로컬 폴더 선택
- 압축파일 선택
- `gvskb` 실행
- 하네스 설치 상태 확인
- 체커 버전 확인
- MCP 설정 확인
- GitHub 접근 확인
- 업데이트 미리보기
- 사용자 승인 후 업데이트 실행

로컬 브릿지는 데스크톱 앱 내부에 포함하거나, 웹 포털이 `localhost`로 호출하는 방식으로 구현할 수 있다.

## 권장 1차 구현

1차는 중앙 서버 없이도 동작해야 하므로 `로컬 웹앱`을 권장한다.

- 브라우저 화면 제공
- 로컬 FastAPI 백엔드 실행
- 백엔드가 `gvskb`와 Git 명령 호출
- SQLite에 검사 이력 저장
- 필요 시 보고서만 사용자가 직접 제출

이 구조는 나중에 중앙 웹 포털로 확장할 수 있다.

## 향후 중앙 포털 확장

2차 이후에는 중앙 포털을 추가한다.

- 각 PC 로컬 앱이 검사 메타데이터만 전송
- 원본 소스, 토큰, 로컬 전체 경로는 전송하지 않음
- 제출 보고서 파일은 사용자가 선택 업로드
- 관리자는 기관 전체 검사 이력, 반복 취약점, 오탐 후보를 확인

## 화면 구조

### 첫 화면

- 서비스명
- “AI로 만든 개발 소스의 보안 위험을 빠르게 확인합니다.”
- 표준 점검 시작
- 빠른 점검
- 설치 상태
- MCP 등록
- 관리자 로그인

### 설치 상태 화면

- 하네스 상태
- 체커 상태
- MCP 연결 상태
- 네트워크 상태
- 상태 점검 시작
- 업데이트 확인

### 업데이트 확인 화면

- 현재 버전
- 원격 안정 버전
- 변경 요약
- 검증 상태
- 업데이트 적용 버튼
- 재검증 버튼

## API 초안

로컬 브릿지 API:

```text
GET  /api/local/status
POST /api/local/update/preview
POST /api/local/update/apply
POST /api/local/validate
POST /api/local/mcp/register
POST /api/scan/start
GET  /api/scan/{scan_id}/progress
GET  /api/scan/{scan_id}/result
POST /api/report/package
```

중앙 포털 API:

```text
POST /api/admin/scan-metadata
GET  /api/admin/scans
GET  /api/admin/scans/{scan_id}
GET  /api/admin/statistics
POST /api/admin/finding-feedback
GET  /api/admin/update-channel
```

## 업데이트 정책

업데이트는 세 단계다.

1. 확인
2. 미리보기
3. 적용

`확인`은 읽기 전용이다. `미리보기`는 원격 버전과 변경 요약만 보여준다. `적용`은 사용자 승인 후 실행한다.

공무원 기본 화면에서는 “업데이트 가능”만 보여주고, 상세 commit이나 내부 필드는 `자세히`에서만 보여준다.

## 보안 경계

- 중앙 서버에 원본 소스 저장 금지
- 토큰 저장 금지
- 로컬 전체 경로 저장 금지
- 업데이트 자동 적용 금지
- 검사 실패를 통과로 표시 금지
- 체커 원본 보고서를 서비스 보고서가 대체 금지

## 하네스와의 관계

하네스는 이 포털의 의존 대상이다.

포털은 하네스를 설치하거나 검증할 수 있지만, 하네스 저장소에 포털 기능을 넣지 않는다. 하네스 저장소에는 공통 정책, 템플릿, 검증 스크립트만 남긴다.
