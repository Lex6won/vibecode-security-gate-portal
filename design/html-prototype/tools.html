하네스 설치

AI 코딩 도구로 업무 도구를 만들 때 기준이 되는 하네스

하네스는 기획 → 설계 → 구현 → 테스트 → 보안점검 순서를 지키도록 돕는 개발 표준 키트입니다. Python, JavaScript, TypeScript 외 언어는 차단하고, 승인된 절차대로 개발하도록 안내합니다.

바로 시작하기

Windows PC에서 GitHub ZIP을 내려받아 설치한 뒤, 만들 프로젝트 폴더에 적용하면 됩니다. AI 코딩 도구를 열고 “하네스 기준으로 시작해줘”라고 말하면 순서대로 안내합니다.

1단계 · 하네스 내려받기

최신 하네스 패키지 (GitHub ZIP) 하네스 ZIP 내려받기

내려받은 ZIP을 모두 푼 뒤, 그 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.

Unblock-File .\install.ps1 .\install.ps1 -InstallPrerequisites -AllowGitHubPilotSource

Windows가 Node.js LTS와 Python 설치를 안내하면 안내에 따라 승인합니다. 설치가 끝나면 %LOCALAPPDATA%\Gyeonggi\VibeCodeHarness\github-pilot에 하네스가 준비됩니다.

설치 파일로 설치하기 (PowerShell 명령 없이)

하네스 설치 파일 정보를 확인하고 있습니다…

2단계 · 프로젝트에 적용하기

만들 업무 도구 폴더를 준비하고, PowerShell에서 아래 명령을 실행합니다. 예시는 TypeScript 웹 도구에 Codex와 Claude Code를 함께 적용하는 경우입니다.

$gg = "$env:LOCALAPPDATA\Gyeonggi\VibeCodeHarness\github-pilot\gg.cmd" & $gg init --project C:\work\my-service --tools both --runtime typescript_web --level L2 & $gg doctor --project C:\work\my-service
AI 도구확인 중… (codex, claude, both 중 선택 가능)
개발 방식python_internal, node_web, typescript_web, typescript_postgres
점검 수준L1 시제품, L2 내부 업무 도구, L3 엄격한 점검

3단계 · 순서대로 개발하기

1

업무를 설명합니다

gg start --brief "민원 처리 현황을 확인하는 내부 웹 도구"

2

화면, DB, 관리자 기능 필요 여부를 결정합니다

gg design --database no --admin no --external-api no --confirm

3

새 패키지를 쓰기 전에 확인합니다

gg package check --ecosystem npm --name example-package --version 1.2.3

4

구현한 뒤 정책과 실행 환경을 확인합니다

gg build로 언어·런타임·정책·설계 조건을 점검합니다.

5

테스트와 보안 점검을 실행합니다

gg verify --run-tests로 테스트와 vibecode-checker 점검을 함께 수행합니다.

6

이관·배포 전 검토 자료를 만듭니다

gg release로 사람 검토에 필요한 자료를 생성합니다.

하네스가 하는 일

개발 순서를 안내합니다기획·설계·구현·테스트·보안점검 순서와 서식을 프로젝트에 넣어줍니다.
허용 언어만 사용합니다Python, JavaScript, TypeScript 외 파일 생성과 실행을 차단합니다.
AI 도구 지침을 적용합니다Codex용 AGENTS.md, Claude Code용 CLAUDE.md와 Hook을 자동으로 설정합니다.
패키지 도입 전 확인합니다npm·PyPI 패키지 이름과 버전을 먼저 확인한 뒤 설치하도록 돕습니다.
보안 점검을 연결합니다vibecode-checker로 코드와 의존성 점검 보고서를 만듭니다.
증적을 남깁니다검토·승인에 필요한 기록을 프로젝트 폴더의 evidence에 저장합니다.

이미 만든 코드가 있다면? 코드 보안 점검

왜 코드만 보안 점검이 필요한가요?

하네스를 쓰지 않고 이미 개발한 코드도 제출·배포 전에 보안 점검이 필요합니다. 하네스 없이 만든 경우에는 개발 순서와 설계 증적이 없으므로, 최소한 코드와 의존성에 위험이 없는지 확인해야 합니다. 폴더만 업로드하면 HTML·JSON 보고서를 받을 수 있습니다.
