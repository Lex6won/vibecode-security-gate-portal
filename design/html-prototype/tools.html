무엇을 설치하나요?

하네스는 AI로 만드는 프로젝트에 공통 개발 기준과 보안 점검 절차를 적용하는 도구입니다.

  • Harness Manager: 프로젝트 폴더와 적용 기준을 선택합니다.
  • AI 도구 지침: Codex와 Claude Code가 같은 기준으로 작업하게 합니다.
  • gg 명령: 개발 과정의 검증과 보안 점검을 준비합니다.
2단계 · 설치

내려받은 파일을 설치하세요.

설치 파일 실행

  1. 다운로드가 끝나면 브라우저의 다운로드에서 설치 파일을 실행합니다.
  2. Windows 설치 창에서 설치를 누릅니다.
  3. 설치가 끝나면 VibeCode Harness Manager가 자동으로 열립니다. 열리지 않으면 시작 메뉴에서 실행합니다.
3단계 · 설정

Manager에서 프로젝트를 설정하세요.

Manager에서 적용

  1. 프로젝트 폴더를 선택합니다.
  2. 사용할 AI 도구, 개발 방식, 점검 수준을 선택합니다.
  3. 적용을 누른 뒤 완료 메시지를 확인합니다.

적용 기준

AI 도구확인 중… (codex, claude, both 중 선택 가능)
개발 방식python_internal, node_web, typescript_web, typescript_postgres
점검 수준L1 시제품, L2 내부 업무 도구, L3 엄격한 점검
명령줄(PowerShell)로 적용하기

예시는 TypeScript 웹 도구에 Codex와 Claude Code를 함께 적용하는 경우입니다.

$gg = "$env:LOCALAPPDATA\Gyeonggi\VibeCodeHarness\github-pilot\gg.cmd" & $gg init --project C:\work\my-service --tools both --runtime typescript_web --level L2 & $gg doctor --project C:\work\my-service
적용 후 개발 순서 보기

AI 코딩 도구에 “하네스 기준으로 시작해줘”라고 말하면 기획 → 설계 → 구현 → 테스트 → 보안점검 순서로 안내합니다.

1

업무 설명

gg start --brief "민원 처리 현황을 확인하는 내부 웹 도구"

2

화면과 데이터 설계

gg design --database no --admin no --external-api no --confirm

3

구현·테스트·보안점검

gg build, gg verify --run-tests, gg release 순서로 증적을 만듭니다.
