업데이트 기준

최신 여부는 공식 안정 릴리스와 로컬 설치본을 비교해 판단합니다.

  • 하네스: 공식 저장소의 검증된 릴리스 또는 승인된 commit 기준 적용
  • 체커: 검증된 패키지 버전과 룰셋·인텔 manifest 기준 적용
  • 업데이트 전 설정 파일을 백업하고 변경 내용을 먼저 표시
  • 업데이트 후 gg-validate.ps1와 gvskb doctor를 다시 실행
  • 경기도처럼 온라인 환경이면 GitHub 접근과 방화벽 허용 상태를 함께 확인

진행상황

선택한 하네스의 준비 상태와 다음 확인 항목을 보여드립니다.

대상 확인선택한 도구와 설치 위치를 확인합니다.
변경 미리보기추가 또는 수정될 설정을 보여줍니다.
실행 승인사용자 확인 후 설치 또는 등록을 진행합니다.
연결 검증하네스와 MCP 호출 가능 여부를 확인합니다.

구버전이 확인되면 이렇게 안내합니다.
