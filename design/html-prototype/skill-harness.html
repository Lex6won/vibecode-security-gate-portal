표준 개발 흐름

하네스 설치

하네스는 설계, 구현, 테스트, 검증을 같은 순서로 진행하게 돕는 개발 기준입니다. 설치하면 커밋 전 점검과 체커 사용 기준을 함께 확인할 수 있습니다.

대상을 선택하면 해당 도구의 설정 위치와 연결 방식을 확인합니다. 설정 파일은 백업과 사용자 승인 전에는 변경하지 않습니다.

개발 중 보안 점검

체커 MCP

체커 MCP를 연결하면 Codex와 Claude Code 같은 AI 코딩 도구에서 개발 중 코드와 프로젝트를 점검하고, 제출 보고서를 생성할 수 있습니다.

코드 조각 점검, 프로젝트 폴더 점검, 제출 보고서 생성 기능을 AI 개발 도구 안에서 바로 호출할 수 있습니다.
체커는 설치된 버전, gvskb doctor, MCP 연결 설정, 공식 업데이트 가능 여부를 함께 확인합니다.

진행상황

선택한 하네스의 준비 상태와 다음 확인 항목을 보여드립니다.

요청 확인선택한 기능을 확인했습니다.
로컬 확인설치 정보와 설정을 읽었습니다.
공식 비교공식 기준을 확인했습니다.
결과 안내완료 내역을 표시합니다.

구버전이 확인되면 이렇게 안내합니다.

업데이트는 자동으로 실행하지 않습니다. 변경 내용과 검증 상태를 먼저 보여주고, 사용자가 승인한 뒤 적용합니다.
