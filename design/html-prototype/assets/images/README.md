# 이미지 교체 안내

이 폴더는 화면에서 사용하는 교체 가능한 이미지 자산을 보관합니다.

## 현재 이미지

- `gg-hero-security.png`
  - 청사형 기본 이미지입니다.
  - 경기도청 신청사 분위기, 보안 방패, 점검 보고서를 함께 보여줍니다.

- `gg-hero-mascot-security.png`
  - 마스코트형 이미지입니다.
  - 봉공이의 색감과 친근함을 참고하되 공식 캐릭터를 복제하지 않은 신규 보안 도우미 이미지입니다.

- `gg-hero-office-mascot.png`
  - 행정형 이미지입니다.
  - 청사와 점검 문서, 안내 캐릭터가 함께 보이는 공공서비스형 이미지입니다.

- `gg-hero-symbol-security.png`
  - 상징형 이미지입니다.
  - 캐릭터보다 방패, 보고서, 제출 패키지 같은 보안 점검 상징물이 중심입니다.

## 교체 방법

1. 새 이미지를 이 폴더에 넣습니다.
2. 같은 파일명으로 교체하거나, HTML의 `src` 값을 새 파일명으로 바꿉니다.
3. 첫 화면 히어로 이미지를 바꾸려면 `main page.html`의 `hero-image` `src` 값을 수정합니다.
4. 권장 비율은 16:9 가로형입니다.
5. 이미지 안에는 공식 로고나 텍스트를 직접 박아 넣기보다, HTML 텍스트와 분리하는 편이 유지보수에 좋습니다.
